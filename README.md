Сборник практических и лабораторных работ по нейросетям и глубокому обучению за выпускной семестр бакалавриата. Все ноутбуки выполнены в **Google Colab**.

## Содержание

| № | Тема |
|---|------|
| 1 | Классификация объектов на изображениях |
| 2 | Использование глубоких нейронных сетей для задач регрессии и классификации |
| 3 | Свёрточные нейронные сети (CNN); классификация и детекция объектов |
| 4 | Построение глубокой свёрточной сети с `BatchNormalization` и `Dropout` |
| 5 | Архитектуры нейронных сетей и **Transfer Learning** |
| 6 | Проектирование автоэнкодеров для прикладных задач |
| 7 | Использование автоэнкодера для **семантической сегментации** |
| 8 | Разработка стратегии тестирования и тест-кейсов (УПИС) |
| 9 | Детекция и классификация объектов моделью **YOLOv12** |
| + | Детекция и классификация в **OpenCV**; развёртывание моделей глубокого обучения |

## Стек

`TensorFlow / Keras` · `PyTorch` · `Ultralytics YOLO` · `OpenCV` · `NumPy` · `Jupyter / Google Colab`

## Как открыть

Каждый `.ipynb` можно открыть напрямую в [Google Colab](https://colab.research.google.com/) (File → Open notebook → GitHub) или локально:

```bash
git clone https://github.com/DenisDrobyshev/universum.git
cd universum
jupyter notebook
```

> Ноутбуки написаны на русском языке и задумывались как учебный материал по прикладному Deep Learning: от простых полносвязных сетей до современных детекторов.
